# SRE Portfolio: Observability & Alerting Stack

## 📌 О проекте
Полноценный стек наблюдаемости и алертинга для микросервиса. Включает в себя сбор метрик, визуализацию «Золотых сигналов», формализацию SLO, генерацию алертов при деградации и нагрузочное тестирование.

## 🛠 Стек технологий
- **Python/Flask** — приложение с экспортом метрик.
- **Prometheus** — сбор и хранение time-series метрик (pull-модель).
- **Grafana** — визуализация и дашборды.
- **Alertmanager** — маршрутизация и управление алертами.
- **k6** — инструмент нагрузочного тестирования.
- **Docker Compose** — оркестрация контейнеров.

## 🏗 Архитектура
[App :8080] --(scrape 5s)--> [Prometheus :9090] --(query)--> [Grafana :3000]
                                  |
                                  +--(alerts)--> [Alertmanager :9093]
                                  ^
                                  |
                           [k6 Load Test] (генерация нагрузки)

## ⚙️ Что настроено
- **SLI/SLO и Error Budget**: формализованные цели надёжности (см. [SLO.md](SLO.md)).
- **Дашборд «Золотые сигналы»**: Latency (p95), Traffic (RPS), Error Rate.
- **Алертинг**: правило `HighLatency` срабатывает, если 95-й перцентиль задержки превышает 300 мс в течение 1 минуты.
- **Инцидент-менеджмент**: алерты маршрутизируются в Alertmanager.
- **Нагрузочное тестирование**: скрипт `load_test.js` для k6 (10 виртуальных пользователей).
- **Самовосстановление**: все контейнеры имеют политику `restart: unless-stopped`.
